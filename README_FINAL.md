# نسخه نهایی اصلاح‌شده سامانه

این بسته برای هماهنگ‌کردن `app.py` با `database.py` فعلی ساخته شده است.

اصلاحات اصلی:
- `get_study_date` و توابع تبدیل تاریخ جلالی/میلادی اضافه شدند.
- دیتابیس‌های قدیمی به‌صورت خودکار با ستون `registered_at_jalali` و فیلدهای `checkin_question` و `checkin_answer` سازگار می‌شوند.
- `get_assessment_responses` فقط Q1 تا Q22 را برمی‌گرداند؛ `assessment_id` دیگر وارد زمینه مربی نمی‌شود.
- ثبت و بازیابی پایش روزانه با سؤال و پاسخ پایش هماهنگ شد.
- برنامه روزهای مختلف از `ensure_daily_interventions` و `day_number` استفاده می‌کند و snapshot هر روز جداگانه ذخیره می‌شود.
- سن و ترم تحصیلی در فرم `app.py` به‌صورت خالی شروع می‌شوند و فقط placeholder دارند.
- خروجی `estimated_level` مدل استانداردسازی شده است و خطای تبدیل برچسب‌ها به «پایین» کاهش داده شده است.

## مهم
فایل مدل شخصی پروژه (`models/random_forest_pipeline.joblib`) باید از پروژه فعلی خودت باقی بماند؛ این فایل در این بسته قرار داده نشده است.

برای استفاده، فایل‌های `app.py` و `database.py` و `ai_coach.py` این بسته را روی نسخه فعلی پروژه جایگزین کن و مدل موجود خودت را حفظ کن.


اصلاحات نسخه v5:
- Estimated Level فقط وقتی نمایش داده می‌شود که خروجی مدل واقعاً به یکی از سه کلاس low/medium/high تبدیل شود؛ در غیر این صورت «نامشخص» نمایش داده شده و خطای واقعی مدل برای پژوهشگر مشخص می‌شود.
- پشتیبانی از کدگذاری رایج کلاس‌های 0/1/2 و 1/2/3 بر اساس classes_ مدل اضافه شد.
- متن معرفی پرسشنامه Solomon and Rothblum به بخش اطلاعات مطالعه اضافه شد.
- عبارت مربوط به «شماره تأیید اخلاق پژوهش» حذف شد.


نسخه نهایی پژوهشی: حالت «روز آزمایشی پژوهشگر» حذف شده و روز مطالعه فقط به‌صورت خودکار از تاریخ شروع محاسبه می‌شود.


نکته استقرار: این بسته کدهای اصلاح‌شده هسته را شامل می‌شود. فایل مدل Random Forest و ماژول‌های پروژه مانند config.py / intervention_engine.py / profile engine باید از پروژه اصلی شما در کنار این فایل‌ها قرار بگیرند. برای اجرای پژوهش واقعی روی Cloud، پایگاه داده پایدار (ترجیحاً PostgreSQL/Neon) استفاده شود و secrets در بخش Secrets سرویس ثبت شوند؛ فایل secrets.toml نباید در مخزن عمومی قرار گیرد.
