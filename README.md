نسخه اصلاح‌شده Estimated Level

اصلاح اصلی:
- ورودی‌های categorical مدل (جنسیت، مقطع، استفاده، دانشگاه، رشتهتحصیلی) دیگر به کدهای عددی تبدیل نمی‌شوند و به همان مقادیر متنی مورد انتظار pipeline داده می‌شوند.
- فقط Age_Num و ترمتحصیلی عددی هستند.
- اگر خروجی مدل معتبر نباشد، estimated_level به صورت not_available نمایش داده می‌شود و سطح پرسشنامه به‌جای خروجی مدل جعل نمی‌شود.
- خطای واقعی model در خلاصه نتیجه برای تشخیص مشکل قابل مشاهده است.

مدل شخصی پروژه را در models/random_forest_pipeline.joblib نگه دارید و جایگزین نکنید.
